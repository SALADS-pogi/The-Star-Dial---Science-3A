## Interface fonts

Oxanium by Severin Meyer and Source Sans 3 by Paul D. Hunt / Adobe are bundled unchanged as variable TrueType fonts in `assets/fonts/` for offline use.

- Oxanium: Copyright 2019 The Oxanium Project Authors. [Official source](https://github.com/google/fonts/tree/main/ofl/oxanium). Complete SIL Open Font License 1.1: `assets/fonts/oxanium-OFL.txt`.
- Source Sans 3: Copyright 2010–2020 Adobe, with Reserved Font Name “Source”; the font binary also carries Adobe's 2023 copyright notice. [Official source](https://github.com/google/fonts/tree/main/ofl/sourcesans3). Complete SIL Open Font License 1.1: `assets/fonts/source-sans-3-OFL.txt`.

The original font names and glyph coverage are retained. See `assets/fonts/README.md` for the download URLs and supported weight ranges.

## IAU / Sky & Telescope constellation charts

The 89 GIF charts in `assets/atlas/` cover all 88 IAU constellations (Serpens has two charts).

Attribution: IAU / Sky & Telescope. Charts by Roger Sinnott and Rick Fienberg; constellation line patterns by Alan MacRobert.

Source: https://www.iau.org/IAU/Astronomy-FAQs/Constellations.aspx

License: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/

Files are bundled unchanged. The Night colors option applies a reversible CSS color filter to the displayed chart. The attribution and license are also shown in the app. Per-chart source links and data provenance are recorded in `ATLAS_REFERENCES.md` and `atlas-iau.json`.
